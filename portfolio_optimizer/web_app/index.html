Max-Sharpe Allocation

Not investment advice. This is an educational demonstration of mean-variance portfolio theory. It does not account for taxes, fees, liquidity needs, transaction costs, or your personal financial situation, and historical returns are a noisy, unreliable estimate of future returns — small changes in the input data can swing "optimal" weights significantly. Consult a licensed financial advisor before making investment decisions.

Closed-form Markowitz solution (matrix inversion, no numerical solver) — allows short positions, unlike the long-only Python version in this toolkit. Weights are annualized from daily return statistics. To use real market data instead of the sample dataset shown by default, run fetch_data_for_app.py (included in the repo) and place the resulting portfolio_data.json next to this HTML file.
